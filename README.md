# Ares Toolkit for ROB RUN (free build)

Download: soon

Free build inspired by the Ares toolkit: a broad module set with off-screen indicators and a compact control panel.

## Modules

| Tab | Content |
| --- | --- |
| Aim | assist, silent, role filter |
| Visual | players, loot, vehicles, cameras |
| Radar | widget, arrows, rings |
| Misc | auto loot, streamproof, profiles |

## Off-screen indicators

Ares adds edge markers for players and loot outside the viewport. Marker size scales with distance, color follows the layer.

## Panel

Search, pinned options, three profiles, keybind editor.

## Install

Admin loader, start ROB RUN, INSERT, load `standard`.

## Troubleshooting

| Symptom | Cause |
| --- | --- |
| no overlay | exclusive fullscreen |
| no menu | not elevated |
| empty tabs | stale build |

Windows 10/11, Steam, EAC.
